
# Blockchain Voting System

## Overview

The Blockchain Voting System is a decentralized platform built for organizational-level elections — ideal for schools, colleges, and corporate environments. It replaces traditional voting methods with a secure, transparent, and tamper-proof process powered by blockchain technology.

An Admin oversees the election lifecycle — setting up the event, registering candidates and voters, and initiating or ending the voting period. Once voting starts, each verified voter can cast their vote only once using their wallet address, ensuring fairness and preventing duplication.

After the election concludes, results are automatically tallied and displayed directly from the blockchain — eliminating manual counting or third-party intervention.
